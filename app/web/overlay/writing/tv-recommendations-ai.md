I have a [discord group of friends](https://gameswiththebois.com) that regularly hangs together - play games, stream movies, watch TV. Normal stuff - Except we watch a lot, and sometimes it's difficult to figure out what to watch next. Classic.

There's so much TV, all coming out on different schedules, on different streaming services. The TV show databases out there only give a generic answer to what's popular. Asking our homie [Claudius](https://claude.ai) directly only gets you info some hits based on last years data - I've tried. Not helpful.

# The idea

What if I could somehow divine our group preferences based on what we've watched previously and judge any new TV that come out against it? So I built it - with [swamp.](https://swamp.club).

First, I'll let you in on a secret - AI sucks at following instructions. It tries, but ultimately, it lets you down. Like a hyped up kid on too much addy with 17 different distractions, lets just say it tends to drift a little from your initial intent.

What it's *great* at is objectively analyzing against a set of principles. In practical terms: `go find me a list of tv shows with this criteria` get's you vastly inferior results to `here's a bunch of metadata about a TV Show - render a verdict based on the following criteria`

Enter [the host](tv-recommendations-ai/host.txt) - generated by distilling about 20MB of yappity over the past couple of years into a rubrick that renders a verdict. Watch or Skip.

Next, a source. I landed on a combination of [Rotten Tomatoes](https://rottentomatoes.com) for list of what's new and what's popular, and then enrich that information from [tmdb](https://themoviedb.org)

Lastly, the results. A markdown table. One row per show, Watch or Skip with a confidence score and the one-line reason `host.md` gave for the call. Sorted by verdict, highest confidence first. Pipe it into Obsidian, paste it into the Discord, doesn't matter — it's just a file. The whole pipeline is one workflow: scrape the browse page, enrich each show via TMDB, fan out one Claude call per show with `host.md` baked into the prompt, aggregate the verdicts into the table.


# Try it out for yourself

The extension is on [Swamp Club](https://swamp-club.com/extensions/@keeb/mms) as `@keeb/mms`. You'll need swamp, node + playwright for the RT scraper, a [TMDB](https://www.themoviedb.org/settings/api) key, and an [Anthropic](https://console.anthropic.com/) key.

```bash
# in a swamp repo
swamp extension pull @keeb/mms
npm install playwright   # node module the RT scraper requires

# secrets
swamp vault put homelab tmdb-api-key      sk-...
swamp vault put homelab anthropic-api-key sk-ant-...

# wire up the three model instances
swamp model create @keeb/rottentomatoes       rottentomatoes
swamp model create @keeb/anthropic/claude     host-evaluator
swamp model create @keeb/mms/tv-recommender   tv-recommender
```

Edit each instance's `globalArguments` to point at your vault keys (and bring your own persona if you like — `tv-recommender` accepts a `personaPath` arg or falls back to the `host.md` bundled with the extension). Then:

```bash
swamp workflow run rt-popular --input limit=20
swamp data get --workflow rt-popular report-keeb-mms-tv-recommendations
```

Swap `rt-popular` for `rt-newest` if you'd rather evaluate what just dropped instead of what's trending. Replace the bundled `host.md` with your own group's profile and you've got a recommender that knows *your* people.
